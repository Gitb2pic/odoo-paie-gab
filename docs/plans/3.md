## 3. Table d'imputation (source : catalogue + `05` §2.4)

Clé `debit` = compte mouvementé dans le sens du signe du montant (débit si positif, crédit si négatif).

| Rubriques | Signe | Débit | Crédit |
|---|---|---|---|
| Gains `BASIC`, `GA_*` catégorie `ALW` (55) | + | compte du catalogue (6611-6618, 6631-6638) | — |
| Avantages en nature `GA_AN_*` (hors `NET`) | + | 6617 | **781** (Q1) |
| `GA_CNSS_SAL` / `GA_CNAMGS_SAL` | − | clé `debit` : 4313 / 4318 → crédit | |
| `GA_TCS`, `GA_FNH_SAL` / `GA_IRPP`, `GA_IRPP_REGUL` | − (régul. ±) | clé `debit` : 4472 / 4471 → crédit (remboursement → débit) | |
| `GA_ADVANCE`, `GA_LOAN`, `GA_ASSIGN`, `GA_GARNISH` | − | clé `debit` : 4212, 4211, 4231, 4232 → crédit | |
| `NET` | + | — | 422 (tiers = salarié) |
| `GA_CNSS_PF` / `_AT` / `_AVID`, `GA_CNAMGS_PAT` | + | 6641 (Q4) | 4311 / 4312 / 4313 / 4318 |
| `GA_FNH` / `GA_CFP` | + | 6413 / 6415 | 4472 |
| `GROSS`, `GA_ROUND_PREV`, `GA_ROUND`, `GA_NET_PAY` | | **sans écriture** (totaux ; le reliquat d'arrondi reste dans 422) | |

Équilibre : Σ débits 66xx = `NET` + |retenues| ; chaque charge patronale et chaque avantage en nature a sa contrepartie → aucune ligne d'ajustement. Un test vérifie que **chaque** règle de la structure est dans la table ou dans la liste « sans écriture » et que le compte débit/gain concorde avec la colonne `account` du catalogue.

La table est en Python (`account_chart_template.py`), clés = xml_id de règle, valeurs = xml_id de gabarit `pcg_*` ; liaison par `ChartTemplate.with_company(société).ref('pcg_xxx')` (pas de recherche par préfixe de code, pas de xml_id de compte en dur dans les données).

## 4. Comportements

- **Configuration** : `_configure_payroll_account_ga(sociétés)` ; appelée au chargement du plan « ga » (nouvelle société), à l'installation (sociétés déjà en « ga ») et par l'action serveur. Structure Gabon → journal `hr_payroll_account_journal` de la société. Compte absent → avertissement journalisé, règle laissée vide (le contrôle ci-dessous bloque).
- **Non-écrasement** (Q3) : ne remplit que les comptes vides ; l'action serveur propose l'écrasement explicite.
- **422 lettrable** (Q2) : `reconcile = True` sur le compte 422 de la société à la configuration.
- **Contrôle bloquant `GA_NO_ACCOUNT`** (patron 8) : une règle de la structure produisant une ligne non nulle sans compte alors qu'elle en exige un → anomalie bloquante sur le lot (évite la ligne « Adjustment Entry » silencieuse).
- **Tiers** : `employee_move_line` sur `NET`, `GA_LOAN`, `GA_ADVANCE` → partenaire = salarié (lettrage du 422 au paiement, suivi des 4211/4212).
- **Regroupement** : option standard `batch_payroll_move_lines` inchangée (une pièce par bulletin par défaut, une par journal et par mois si cochée) — RG09.
- **Rapprochements** : `res.company.l10n_ga_payroll_liability_balance(kind, date_from, date_to)` → `{code: solde}` pour `kind='tax'` (4471, 4472) ou `'social'` (4311, 4312, 4313, 4318) ; réutilisé par `l10n_ga_dgi_edi` (ID10 payée, DTS payée).
