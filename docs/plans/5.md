## 3. Conception

- **Tiers** : `l10n_ga_fee_category` (A administrateurs / commissaires aux comptes, B courtiers / intermédiaires, C honoraires : avocats, notaires, huissiers, experts-comptables ; prestations de services ; loyers), `l10n_ga_is_resident`, `l10n_ga_zone` (CEMAC / hors CEMAC, déduite du pays), `l10n_ga_vat_subject` ; `l10n_ga_withholding_kind` calculé : non-résident → 20 % ; résident non assujetti à la TVA classé (hors loyers) → 9,5 % ; la position fiscale du tiers (par société) suit automatiquement.
- **Taxes** : `l10n_ga_ras_095` (−9,5 %) et `l10n_ga_ras_20` (−20 %, modifiable : point 09-7), achats, retenue au paiement, séquence de pièces de retenue par société, compte 4478, groupe « Retenues à la source ».
- **Facture fournisseur** : la retenue correspondant à la position fiscale est ajoutée aux lignes ; l'autre retenue est retirée. **Anti-double retenue** : contrainte sur les lignes de facture et les lignes de retenue de paiement (jamais 9,5 % et 20 % ensemble, jamais 9,5 % pour un non-résident) + contrôle de déclaration.
- **ID18 / ID27** (mensuels, le 15 M+1, date de paiement) : retenues et bases des écritures de paiement validées du mois, par bénéficiaire (avoir en négatif) ; gabarits officiels (liste de 10 lignes, feuillets supplémentaires de l'ID18 ; au-delà, feuilles copiées) ; détails avec `move_line_ids`.
- **ID23 / ID24 / ID26** (annuels, 30 avril N+1) : sommes versées dans l'année = part HT des factures fournisseurs réglée dans l'année (lettrages datés de l'année), retenues lues sur les paiements ; ID23 : résidents classés A / B / C, sections « salarié » (contact d'un salarié) / « non salarié » ; ID24 : non-résidents, CEMAC / hors CEMAC, retenue 20 % ; ID26 : prestataires non assujettis, retenue 9,5 % ; classeur neuf mis en forme (gabarits `.xlsm` de la V1 absents, D-87).
- **Contrôles** : bénéficiaire non classé, NIF manquant (résidents), retenue absente sur un fournisseur classé payé, double retenue ; ID26 ↔ Σ ID18 de l'année, ID24 ↔ Σ ID27.

## 4. Tests

ID18 et ID27 sur un mois : facture, paiement partiel, deux paiements, avoir ; non-résident → 20 % seul (contrainte) ; ID23 / ID24 / ID26 sur une année ; ID26 = Σ ID18 ; multi-société ; gabarits remplis (valeurs, aucune formule).
