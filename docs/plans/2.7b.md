## 1. Structure du modèle

| Zone | Contenu du modèle |
|---|---|
| En-tête gauche (cadre) | logo, raison sociale, adresse, B.P., téléphone, n° CNSS employeur |
| En-tête droit | titre « BULLETIN DE SALAIRE » ; période du … au … ; date de paiement ; « Édité le » ; matricule, date d'embauche, n° CNSS, n° CNAMGS, situation familiale ; horaires (heures du mois), nombre d'enfants, nombre de parts |
| Bloc salarié gauche | emploi, direction, département, catégorie, mode de paiement + banque, n° de compte |
| Bloc salarié droit (grisé) | civilité + nom, ville (adresse) |
| Tableau central | colonnes : Code · Libellé · Base ou nombre · Taux · Montant (gains et cotisations **salariales**) · Taux · Montant (cotisations **patronales**) · colonne libre |
| Ordre des lignes | salaire de base (nombre de jours × taux journalier) ; absence non payée (ligne négative, jours × taux) ; **TOTAL BRUT** ; cotisations sur **une ligne par organisme** avec base, taux et montant salariaux **et** taux et montant patronaux sur la même ligne (CNSS, CNAMGS, FNH, CFP…) ; **TOTAL COTISATIONS** (salarial et patronal) ; avantages en nature + total ; base TCS (ligne d'information) ; TCS ; IRPP ; indemnités non imposables (logement, transport, bonus, domesticité) ; **TOTAL GAINS**, **TOTAL RETENUES**, **NET À PAYER** |
| Pied | mention « conservez ce bulletin sans limitation de durée » ; tableau **Cumuls** (lignes Mois / Année ; colonnes salaire brut, charges salariales, avantages en nature, TCS, IRPP, FNH, indemnités non imposables) ; cadre **Net à payer** ; tableau **Congés** (base congés, jours de congé principal : acquis / pris / solde) ; cadres **Émargement employeur / employé(e)** |

## 2. Écarts avec le bulletin actuel (étape 2.7)

| # | Écart | Correction proposée |
|---|---|---|
| E1 | En-tête générique (`web.external_layout`), pas de cadre employeur ni de bloc d'identité en deux colonnes | mise en page propre (`web.basic_layout`) reproduisant les deux cadres ; logo de la société |
| E2 | Colonnes gains / retenues / patronal séparées ; une ligne par règle | colonnes du modèle ; **part salariale et part patronale sur la même ligne** par organisme (CNSS patronale = somme des branches PF + AT + AVID) |
| E3 | Base et taux absents (nos lignes ont quantité 1, taux 100) | base et taux **figés par ligne** à la validation (`hr.payslip.line`), lus sur le résultat du noyau et les paramètres du bulletin |
| E4 | Salaire de base proratisé sur une seule ligne | présentation en deux lignes : salaire mensuel (jours × taux journalier) puis absences non payées (ligne négative) — **affichage seulement**, le calcul de `BASIC` reste proratisé (défaut B2) ; salaire contractuel figé |
| E5 | Ordre des rubriques = séquence technique | ordre du modèle : gains soumis → total brut → cotisations → avantages en nature → TCS / IRPP → indemnités non imposables → totaux |
| E6 | Totaux absents (TOTAL BRUT, TOTAL COTISATIONS, TOTAL GAINS, TOTAL RETENUES) | calculés depuis les lignes stockées |
| E7 | Cumuls incomplets (pas de charges salariales, avantages en nature, FNH, indemnités non imposables ; pas de ligne « Mois ») | nouveaux cumuls figés + champs correspondants du cumul d'ouverture (défaut 0) ; tableau Mois / Année |
| E8 | Pas de tableau des congés | base congés et jours de congé payé acquis / pris / solde figés à la validation (allocations et absences du type « Congé payé ») |
| E9 | Pas d'horaires, de direction, d'adresse, d'« Édité le », d'émargement | heures du mois (prestations stockées), direction = service parent, ville du salarié figée, « Édité le » = date de validation (réimpression identique), cadres d'émargement |
